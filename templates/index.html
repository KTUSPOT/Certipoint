Python Module Integration

Person 2 simply imports `analyse_certificate` and passes the structured dictionary:

from person3_validation import analyse_certificate

# Input dictionary from Person 2
person2_output = {
    "student_name": "Jithu",
    "activity": "Blood Donation",
    "organization": "NSS Unit",
    "date": "15-08-2026",
    "certificate_id": "NSS12345",
    "category": "Social Service",
    "level": "Participation",
    "confidence": 0.95
}

# Person 3 performs validation, duplicate check & point calculation
result = analyse_certificate(person2_output)
print(result)
